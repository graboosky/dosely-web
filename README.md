# Dosely — Web

Dosely is an iOS medication tracker that logs pills, injections and other treatments, and uses AlarmKit to make sure no dose is missed.

This is the **web** platform repository of the Dosely container: a static site (marketing,
privacy policy, support) published on GitHub Pages at https://graboosky.github.io/dosely-web/.
Conventions are in [`CLAUDE.md`](CLAUDE.md); product behavior and copy live in the
container: `../CLAUDE.md` and `../docs/domain.md`.
